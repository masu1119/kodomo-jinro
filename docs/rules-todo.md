## 入れたいこと

1. **自分の画面を人に見せない**
   - 今までは「ほかの人の がめんは 見ないでね」だけだった。画面を見せて役職を証明すると、推理ゲームにならない
2. **いなくなった人は、役職をないしょにして、話し合いでは静かに見守る**
   - ゲームの画面でも「へった人の やくわりは ひみつだよ」としているので、それに合わせる
3. **勝ち負けの説明を正しくする**
   - 前は「うそつきが なかまと おなじかず まで ふえたら」だったが、オオカミは増えない
   - 正しくは「なかまが へって、オオカミと おなじ かずに なったら オオカミの かち」
4. **説明に足すこと**
   - 決選投票でもまた同じ票数なら、ルーレットで決まる
   - フクロウ・イヌ・キツネの力(イヌは自分を守れず、同じ人を2日続けて守れない)
   - 投票で選ばれた人がどうなるか(今は「森を はなれる」。下の「言葉づかいの方針」を参照)

## 言葉づかいの方針

- **最終的には物語調でそろえたい**(`story` の枝の「つきよの森と うそつきオオカミ」の路線)
- それまでの仮の表現として、投票で選ばれた人は「🌲 ◯◯ は 森を はなれることに なったよ。」にしている
  - 「おうちに かえる」から変更。追い出す感じを、怖くなりすぎないマイルドな言い方にした
  - 物語調の候補:「🌙 ◯◯ は みんなに 森の いりぐちまで おくってもらったよ。このゲームでは もう もどれないよ。」など
