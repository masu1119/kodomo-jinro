# こどもじんろう

「うそつきを見つけだせ」— ブラウザ1つで遊べる、子ども向けの人狼ゲームです。
1台のスマホ(タブレット)を順番に回して遊びます。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。ビルドや通信は要りません。

## 役職

- 🐺 うそつきオオカミ(人狼)
- 🐰 なかよしウサギ(村人)
- 🦉 ものしりフクロウ(占い師)
- 🐶 まもりイヌ(狩人)… 6人以上で登場
- 🦊 いたずらキツネ(狂人)… 7人以上で登場。オオカミの味方だが、占っても「オオカミじゃない」と出る(フクロウにわかるのはオオカミかどうかだけ)

遊べる人数は 4〜9人です。
