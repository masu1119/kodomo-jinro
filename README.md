# こどもじんろう

「うそつきを見つけだせ」— ブラウザ1つで遊べる、子ども向けの人狼ゲームです。
1台のスマホ(タブレット)を順番に回して遊びます。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。ビルドや通信は要りません。

## 役職

- 🐺 じんろうオオカミ(人狼)… 8人以上で2匹。オオカミ同士はお互いがわかる。夜は1匹目が選んだ人を2匹目に見せて、2匹目が「そのまま」か「別の人」を選んで最終決定する
- 🐰 むらびとウサギ(村人)… 夜は森を探検してアイテムを集める(勝ち負けには関係ない)。集めたものは次の夜から一覧で見られる
- 🦉 うらないフクロウ(占い師)… 夜の番に、これまでに調べた結果(最初のヒントも含む)をまとめて見られる
- 🐶 きしイヌ(騎士・狩人)… どの人数でも1匹いる。自分は守れず、同じ人を2日続けて守ることもできない
- 🦊 うらぎりキツネ(狂人・裏切り者)… 5〜7人と9人で登場。オオカミの味方だが、占っても「じんろうじゃない」と出る(フクロウにわかるのはじんろうかどうかだけ)
- 🐈‍⬛ れいばいクロネコ(霊媒師)… 8人以上で登場(じんろうが2匹のときだけ)。投票で森をはなれた人がじんろうだったかを、その夜の番に知る。これまでの結果もまとめて見られる。キツネは「じんろうじゃなかった」と出る。夜はウサギと同じく森を探検し、霊媒の結果は探検のあとの画面に出る(タップの回数をそろえて正体がばれないように)

遊べる人数は 4〜9人です。

夜の番は、どの役職でもタップの回数が同じ(4回)で、画面の長さもその夜の全員でそろえています(いちばん長い人の画面に合わせて、ほかの人の画面にも余白を入れる)。スクロールの有無や量、操作の回数から正体がばれないようにするためです。
