# こどもじんろう

「うそつきを見つけだせ」— ブラウザ1つで遊べる、子ども向けの人狼ゲームです。
1台のスマホ(タブレット)を順番に回して遊びます。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。ビルドや通信は要りません。

## 役職

- 🐺 うそつきオオカミ(人狼)… 8人以上で2匹。オオカミ同士はお互いがわかる。夜は1匹目が選んだ人を2匹目に見せて、2匹目が「そのまま」か「別の人」を選んで最終決定する
- 🐰 なかよしウサギ(村人)… 夜は森を探検してアイテムを集める(勝ち負けには関係ない)。集めたものは次の夜から一覧で見られる
- 🦉 ものしりフクロウ(占い師)… 夜の番に、これまでに調べた結果(最初のヒントも含む)をまとめて見られる
- 🐶 まもりイヌ(狩人)… 6人以上で登場。自分は守れず、同じ人を2日続けて守ることもできない
- 🦊 いたずらキツネ(狂人)… 7人と9人で登場。オオカミの味方だが、占っても「オオカミじゃない」と出る(フクロウにわかるのはオオカミかどうかだけ)

遊べる人数は 4〜9人です。
